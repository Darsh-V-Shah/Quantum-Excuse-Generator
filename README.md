# Q.E.G. — Quantum Excuse Generator ⚛️

**Classical excuses are predictable. Quantum excuses aren't.**

Q.E.G. (Quantum Excuse Generator) is a procedural, rule-based excuse generation system that turns ordinary situations into increasingly absurd pseudo-scientific explanations inspired by concepts from quantum mechanics.

Enter a mundane problem, choose a quantum mode, and collapse the wave function to generate an excuse. Then keep escalating it until the laws of reality become optional.

### ⚛️ Features

* **8 Quantum Modes** — Schrödinger, Heisenberg, Many Worlds, Entanglement, Quantum Tunneling, Thermodynamic, Black Hole, and ABSOLUTELY UNHINGED.
* **Progressive Escalation** — Continuously make an excuse more quantum while maintaining its narrative.
* **Quantum Telemetry** — Simulated probability amplitudes, timeline scans, observer effects, and plausible-deniability calculations.
* **Dynamic Metrics** — Quantum Coherence, Scientific Confidence, Believability, Professor Hostility, and Unhingedness.
* **Persistent Lore** — Wi-Fi routers, attendance servers, temporal feedback loops, and eventually the university timeline itself.
* **Random Scenarios** — Generate unexpected incidents for spontaneous quantum experimentation.
* **Quantum Reports** — Export a complete record of the collapsed excuse, universe, mode, escalation level, and system lore.
* **Interactive Web Interface** — Built with Python and Gradio.

### 🧪 How It Works

Q.E.G. does not use an LLM or a fixed database of complete answers. Instead, it uses **procedural generation**: it detects concepts in the user's situation, selects relevant templates and quantum mechanisms, and combines them with dynamically selected components. Increasing the escalation level introduces additional causal disruptions and quantum phenomena.

The result is a system that can produce different excuses from the same basic situation without requiring a generative AI model.

### 🛠️ Tech Stack

### 🚀 Run Locally

```bash
pip install "gradio>=5.0,<7.0"
python qeg.py
```

Then open the local Gradio interface in your browser.
